## Notes

Measured at 918 characters; the box caps at 1000.

```
Bracket is four composable Intelligent Contract primitives for judgments about SETS rather than single items. The idea: never ask the network to agree on a measurement, ask it to agree on a STRUCTURE derived deterministically from it. Two validators will not agree a thing scores 7.3 not 7.6; they will agree it beats its neighbour. A ladder of decreasing precision. Slate orders N items and bands ties, so consensus is strict_eq on a canonical rank vector, not raw scores. Cutline picks the top K, agreeing only on membership, and declares up front whether an arbitrary cut refuses or expands. Winnow partitions into accept/reject/review, forgiving one boundary item and only through review. Tiebreak is the atom the other three call: one comparison in BOTH presentation orders in a single nondet block, returning TIED when the answer moved. All four are live on studionet, each with a success and a refusal on chain.
```

## What clears the bar, line by line

The category rejects "thin LLM wrappers" and "generic AI decides X demos".

- **The model never decides.** In all four the model produces a comparison or a
  score. The outcome comes from a pure function in the deterministic half,
  against rules frozen on chain before the model ran. Swap in a worse model and
  the mechanism still works — it just refuses more often, which is the correct
  response to a worse model.

- **The validator function is the contribution.** Each contract exists to
  demonstrate one agreement rule, and each rule is shown as code in
  [README.md](README.md) and specified in [CONTRACTS.md](CONTRACTS.md).

- **It is a library, not a grab bag.** Tiebreak is the atom; the other three are
  compositions of the same question. A reviewer who sees four unrelated
  contracts reads a pile. A reviewer who sees an atom and three compositions
  reads a catalogue.

- **Refusing is designed.** `tied`, `undifferentiated`, `cut_is_arbitrary` and
  `standard_too_vague` are first-class stored results, not error paths.

- **The tests have teeth.** A passing count is a claim; the mutation table in
  [README.md](README.md) is evidence, and it is generated by a script that
  refuses to emit a table if anything escapes.

- **It runs with nothing installed.** `pip install pytest && pytest tests/ -q`.
  A reviewer with two minutes and no API key can verify every claim.

- **The limits are stated.** [DECISIONS.md](DECISIONS.md) says what each
  contract cannot do, including the bias Tiebreak structurally cannot detect,
  and records the two mutations that could not be caught rather than quietly
  dropping them.
